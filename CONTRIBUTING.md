# Contributing

Thanks for your interest in improving this project.

## Before making changes
1. Open an issue describing the bug or improvement.
2. Keep changes focused and explain any behavior changes.
3. Never commit `.env`, API keys, or private conversation data.

## Local checks
Install dependencies and run:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

## Pull requests
Include a clear summary, steps to reproduce any bug, and screenshots for visible changes. Do not claim tests passed unless you ran them.
